# To-Do приложение на FastAPI

## Возможности

- ✏️ Создание, чтение, обновление и удаление задач  
- ✅ Отметка о выполнении / невыполнении  
- ⏰ Установка напоминания на любую будущую дату и время  
- 🔍 Фильтрация задач по статусу выполнения  
- 📄 Пагинация (`skip` / `limit`) на главной странице  
- 🌐 REST API с ответами в формате JSON  
- 🧹 Адаптивный интерфейс на Bootstrap 5  
- 🧪 Валидация: напоминание нельзя установить в прошлом  

## Технологии

- **Backend**: FastAPI, SQLAlchemy (ORM), Pydantic (валидация)  
- **База данных**: SQLite (`database.db`)  
- **Frontend**: Jinja2, Bootstrap 5, CSS  
- **Сервер**: Uvicorn
